# 单次浏览器执行上下文

browser_operate 的 task 策略共用一个执行上下文：它记录本次调用内的初始/当前观察、变化、最近动作和操作焦点。Roll仍管理用户目标、授权、整个任务和跨调用进度；上下文不会自行生成下一项业务任务。

## 代码结构

```text
browser_operate / task-loop.ts
  └─ execution-context.ts：生命周期、观察版本、变化、动作与焦点
      ├─ task-progress + task-progress-policy：读取证据与返回（A）
      └─ form-context + form-policy：明确字段委派、当前满足状态与局部操作
```

Jev HTTP客户端保持无状态。共享层属于browser-use执行器，也适用于该循环的其他决策引擎；当前真实模型验证使用TypeSafe官方Jev。

## 表单委派

```json
{
  "strategy": "task",
  "engine": "jev",
  "model": "jev-1.13.0",
  "pageId": "当前页面ID",
  "allowedOrigins": ["https://example.com"],
  "goal": "将职位名称设置为门店服务员，经验不限，地点不改，不保存。",
  "values": [
    {"name": "目标名称", "text": "门店服务员"},
    {"name": "目标经验", "text": "不限"}
  ],
  "formTask": {
    "mode": "edit",
    "stopAt": "applied",
    "fields": [
      {"name": "职位名称", "intent": "set", "valueName": "目标名称"},
      {"name": "经验要求", "intent": "set", "valueName": "目标经验", "comparison": "semantic"},
      {"name": "工作地点", "intent": "preserve"}
    ]
  },
  "blockedNames": ["保存", "发布", "删除"]
}
```

- mode由Roll指定为create/edit，不能从空字段猜测。
- set表示本次允许写入，valueName必须在values中唯一存在。集合内的联动重置可以修复；辅助values不自动成为待办字段。
- preserve是只读保留：基线来自本次首次观察，不直接写回。若明确允许恢复旧值，Roll应以set提供那个目标值。缺少初始证据不能中途猜一个基线。
- comparison默认auto：文本和复选状态严格比较，已识别的picker/native select从当前选项映射目标，按应用值读回；literal显式要求完整一致，semantic显式要求语义等价。判断仅消费当前可读的已应用值；结果随字段身份、值、约束或有效性改变失效，菜单展开和显示图标变化不单独失效。
- stopAt=applied要求编辑器关闭且主表单当前值满足；current-view允许在当前编辑视图设置后保持打开。两者都不表示服务器已保存。
- readTask与formTask互斥，均只支持strategy=task；不传时保留原有调用兼容，仍有共享观察变化记录。

## 执行规则

Jev先从本轮观察中识别所委派字段或编辑入口，代码保存绑定；仅当选中的动作不再符合更新后的委派条件时丢弃，否则在原目标校验后继续执行。后续直接比较当前可读值；同一picker和经过确认的当前编辑弹窗内可执行必要操作，已满足的字段不再提供重复写入候选。

当前状态分为satisfied、unsatisfied、unknown。节点消失、遮挡、截断、查询词尚未应用等不会被当成空值；明确的页面invalid标记不会因文字相同而被忽略。两个独立字段即使目标值相同，也不能绑定到同一个可比较控件。

当字段已满足指定终点时，候选只剩结束或交回，不再提供会继续修改/应用的动作。表单路径不再额外询问一个全任务完成裁判；当前字段证据与本次终点决定本次委派是否完成，交回前仍重新观察，Roll继续统一验收。

枚举映射由Jev从已观察选项选择，代码记住目标标签及字段/选项集合约束；关闭菜单后保留映射，值重置时在本次范围内修复。节点、owner、相关约束或已观察选项集合改变时重新映射。该映射不证明点击成功，完成仍需当前已应用值读回。

没有每字段宿主辅助调用。映射、必要语义判断和新弹窗归属问题复用同一Jev请求；新判断改变执行前提时丢弃旧动作。字段顺序由Jev根据前置依赖、必填项和当前焦点选择，代码没有写死岗位阶段或网站路径。

## 通用编辑入口

表单字段分开记录实际值控件 `binding` 和编辑入口 `entry`。入口可以是展示摘要的可点击文本；Jev 根据当前标签和上下文，独立判断每个委派字段是否通过这个入口编辑。多个字段可以关联同一入口，但不允许把同一个实际值控件绑定给多个字段。共享层没有薪资、日期或 BOSS 专用字段类型。

入口归属与摘要值分开失效：同一节点的摘要文字变化只撤销旧完成证据；节点、角色或周边标签变化则撤销入口关系。弹窗内保留所有通过该入口关联的委派字段，并重新绑定实际输入/选择器。局部编辑器已有绑定的选择器时，不把弹窗归属当成其他选择器的操作权限。

关闭编辑器后，主表单若只显示摘要，Jev 在现有批量请求中分别判断摘要是否明确证明每个字段的目标值。该判断不是把摘要字符串写入子控件；无法判断时保持 unknown。上下限共享单位等常见展示记法由模型理解，代码不解析业务字段。摘要证据变化后需要重新判断；不增加逐字段宿主调用。

## 返回结果

execution包含invocationId、revision、最新观察、最近动作、focus、变化和form字段状态。变化记录包含前后值及关联的最近动作，scope为delegated/preserved/unassigned；这表示观察顺序，不是因果证明。

unassigned表示未绑定到本次委派，不能断言必然属于某个业务字段，也不能自动修复。保留字段发生值变化、文档被替换、字段/弹窗归属不明确时交回；不确定派发不会自动重放。

interaction_done只表示本次委派在当前页面达到条件，verified始终false。整个用户任务是否结束、后续任务、是否保存/发布由Roll决定。

## 输入与生命周期

初始值与最近已知值留在本次调用内；中间不可见后再次出现可以识别值改变。变化窗口最多32项，给模型只发送近期摘要。字段定义最多16项，完整目标值留在代码中比较；模型预览限长并保留长度信息。

绑定问题发送候选ref及简短标签、周边字段语义和组内位置；完整观察仍放在共享elements中。压缩器显式保留适配器仍需读取的ref，不能因它暂时不可执行而丢掉编辑入口。

没有跨调用恢复、第二份session或长期业务完成清单。仍保留原有输入总预算；大页面自适应裁剪与导航能力不在这次改动范围。

## 验证边界

验证使用隔离Chrome真实DOM与TypeSafe官方Jev，涵盖联动字段、弹窗应用、当前视图停留、范围外变化只报告、保留字段变化交回；同时回归读取A和原有联动表单。真实BOSS已发布岗位没有被修改。本次结果不构成任意站点/复杂摘要控件的稳定性保证。

## 可达性与绑定修复

滚动容器裁剪的选项与无关遮罩分开判断。已观察到且可通过滚动到达的选项交给现有native click执行滚入视图和命中检查；探索未显示/虚拟列表选项时，在当前picker内提供滚动锚点。字段绑定按文档、节点、控件角色与字段/owner关系保持连续，picker显示值和图标不作为身份；节点替换或owner改变仍重新绑定。

被遮住但能重新读取的已应用DOM值可以支撑字段状态，不能支撑点击授权。无新鲜读值证据时仍为unknown。更新无关字段的语义证明不再强制丢弃当前仍合法的动作，同批问题仍保持独立，未知绑定造成的真实依赖继续分轮。

同一局部字段组附带按可见布局计算的位置和总数，Jev按明确标签优先、同组顺序辅助区分上下限。位置是观察事实，不写入业务字段名。已经被form范围过滤掉的TYPE_TEXT候选不再携带无用的值选择问题；字段清单使用短摘要，保持48KB预算。非form委派不增加这份字段清单。

## 长列表与搜索选择器

48,000字节为JSON预览的软压缩目标，128,000字节为本地资源保护上限，均不代表模型token上限。Jev 1.13官方限制为state加全部问题64k tokens、state加最长问题32k tokens，由provider验证；没有使用未经校准的字节/token换算。压缩保留原始目标与动作ID，合并重复context，裁剪状态值预览；错误说明仅下一次请求未发出，不否认之前已执行的动作。

字段绑定只考虑输入、picker、带标签的控件和编辑按钮，不把长列表中的普通展示行当作每个缺失字段的绑定候选。弹窗期间推迟无关字段绑定，但保留当前弹窗的控件证据。

自动补全支持局部唯一文本输入与隐藏选择值配对的控件：菜单打开或尚无选择值时，输入文字是query；必须点击结果，关闭菜单后有选择证据才是committed。普通form上的隐藏字段不用于推断配对。相同选项的子节点按optionPath去重，首行label用于已选显示值，全行文字仍作为上下文。

弹窗归属问题直接引用currentEditor的目标字段、标题和控件；判断其用途，不要求目标已出现在默认类目。确认相关后，可让Jev选择搜索框并仅在该弹窗内执行查询，查询值不能作为主表单已完成证据。

确认或操作字段弹窗时，模型视图收敛到currentEditor、该字段及弹窗控件，原始goal保持完整。整张表单状态仍由执行循环持有并执行保留字段变更检查；关闭弹窗后恢复全表单视图，不按被裁剪的模型视图宣告任务完成。

## 可达性与交互反馈

委派内共享观察区分真正遮挡和可滚动显露。`scrollContainerPaths` 是同源文档内实际滚动祖先的稳定路径；固定边缘遮挡需要显式滚动时设置 `revealViaScroll`。这类目标继续参与字段关联，但在新观察确认可操作前不会成为点击/输入候选。执行前的原生命中检查保持生效。

局部交互记忆将派发结果与下一观察配对，保留有界原文反馈。表单中连续无效果的同目标操作暂时抑制；一个批内独立 Jev Choice 可识别反馈明确要求的已委派前置字段，值变化后重新开放尝试。布局、ref 更新和 toast 消失不算任务进度。普通浏览缺少字段效果证据时仅提供反馈，不据此硬拦截导航动作。执行超时或派发不确定不自动重试。

静态 preserve 字段可使用 `DISPLAY:` 只读关联：模型选择字段对应的自身展示值，代码比较调用开始的完整基线与当前证据。它不会创建写权限，也不会把后来出现的值当作初始值。Roll 仍负责整个任务的最终验收。
