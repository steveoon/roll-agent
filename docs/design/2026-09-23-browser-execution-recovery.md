# 浏览器委派内的可达性、反馈记忆与只读证据

状态：已实施并完成新建/编辑各两轮实测（2026-09-23）。延续 2026-09-22 execution context，作用域为一次 browser_operate。

## 边界

Roll 拥有原始任务、授权和跨调用规划。Jev 判断控件语义、填写顺序和页面反馈所指的前置条件；代码负责候选、状态有效性、CDP 执行和禁止动作边界。禁止逐字段宿主辅助、站点专用规则和将任务完成等同于动作派发成功。新增状态随调用结束释放。

## 可达性

区分真正遮挡、视口/可滚动容器裁切、隐藏与可用。iframe 祖先检查必须保留真实遮挡判断；只有观察能证明可滚动显露时，才提供该动作。执行时使用原生 CDP reveal，再做已有命中检查。滚动观察包含控件自身的可滚动区域，锚点只用于其最近的滚动容器，避免多行输入框吞掉外层滚轮。滚动候选应以未满足字段及其容器为目标，不能把 frame 的最后一个元素任意当作滚动区域。不可安全判断的情况保留 unknown/covered。

## 局部反馈记忆

将已执行交互与下一次观察配对，记录目标、原始页面反馈、是否发生目标值/面板变化。点击无效果不能当作选择已应用。一次同状态无进展后，将有界反馈和委派字段候选提供给一个独立 Choice：哪个尚未满足的字段是页面明确要求的前置条件，或 NONE。该问题与普通动作选择合并在同一 Jev 请求里；答案独立，代码更新依赖后重新校验原动作是否仍可执行。

同一个目标及操作无效果两次时暂时抑制；重新生成 ref、布局、toast 消失和时间变化不重置计数。有明确依赖时仅在依赖的当前值/目标值发生变化后允许再试；无明确依赖时在表单实际值或面板变化后允许再试。错误或不确定派发不自动重放。记忆最多 32 项、反馈最多 4 条每条 400 字符；文档变化清空。

## 只读保持证据

preserve 可绑定有局部语义和稳定身份的 display-only 读值，不能因此获得写权限。初始值来自委派开始的观察；以后新出现的值不能冒充初始值。当前证据不可读/隐藏时 unknown，变化时 unsatisfied；不自动恢复未授权字段。

## 字段定位与空值

控件身份和当前值证据独立：已绑定的空 picker 在局部编辑器中可以继续进行选项映射，不能因为 placeholder 没有可比较值而每轮重新定位。字段状态仍保持 unknown，不能把候选选项当成已填写值。字段定位问题按 set/preserve 分开，set 明确允许宽泛编辑入口对应多个子字段；选项描述以实际按钮文字开头，避免有限预览先保留说明前缀而截掉有效标签。关系仍由 Jev 根据页面观察判断，代码不内置业务字段规则。某个子字段绑定有歧义时，仅撤销其绑定和目标映射，其他已明确的兄弟字段可以继续推进；无可执行进展时仍由原有停滞边界交回 Roll。

## 验证

通用 Chrome 页面覆盖嵌套 iframe/滚动、固定底栏、遮挡和隐藏反例；合成循环覆盖前置条件反馈、toast 消失、ref 重生、局部变化后重试、静态 preserve 值变化。官方 Jev 集成验证是否实际消费新状态。BOSS 使用原测试资料，固定视口并记录可见性，至少新建/编辑各两轮；最终独立 DOM 验收，不保存或发布。CDP 五秒超时保持原行为；采集环境和失败命令诊断，不先猜测显示器切换原因或增大超时。
