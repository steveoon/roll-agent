# Task 1：输入持久化结论（2026-10-10）

> 历史结论摘要，仅适用于当时的测试快照，不代表当前代码验收。

基线 `dev@31816c3`。当时独立验收通过，范围仅为输入接收、持久化和中断保留。

- 维护、Skill 加载和推理之前先持久化原始输入；失败、取消、超时及内部续跑不会丢失或重复追加已接收的输入。
- SQLite v8 增加按 thread/input ID 唯一的接收记录；消息与记录在同一事务提交。相同 ID 的幂等重试与用户主动发送相同文本是两件事。
- Skill 只持久化名称、来源和哈希引用；正文只在当前回合使用。重开、恢复或 fork 不重新加载旧正文，fork 不继承执行授权。
- 必要持久化失败停止推理；无 Store 的会话只有进程内保留能力。旧 `onPersist` 集成需支持分批追加。
