为交互式 ChatGPT 会话增加同一轮内的有界断网恢复：默认最多恢复五次，依次等待 1、2、4、8、16 秒，保留原输入、截止时间、步数与已完成的工具结果，只重新生成未完成的模型步骤。恢复期间显示低调的“恢复连接中”，丢弃失败步骤的临时文本与推理，不重复添加用户消息或重启后台命令。

Runtime 通过显式可选策略启用恢复；存储失败、权限/额度/协议错误、用户拒绝、取消以及结果未结算的工具均不自动重试。重新生成的工具调用仍需校验和审批，非交互入口、其它 provider 和公开 Runtime 协议维持原行为。
