支持指定未来开始时间的间隔任务，以及每天/每周的日历任务。默认使用运行 Roll 的机器时区，创建时保存日历时区；CLI 与聊天创建、确认、列表和追加轮数沿用同一规则。保留自动轮数、重试、单例和最多一次补跑语义，明确处理夏令时跳时/重复钟点。调度账本升级至 v9 并保留旧任务与历史，升级后需重启调度服务。

规范化时区别名，区分创建输入与严格持久化规则。为已打开的旧连接增加写入版本隔离，旧 daemon 在登记／迁移前被识别并要求重启，服务维护只读检查占用。终端确认支持完整参数翻页，配置台按任务时区显示执行时间。

查询连接优先使用原生 readOnly，并启用 query_only SQL 写保护，兼容 Node 22.6–22.11 的历史、更新和服务维护查询；快照读取显式结束事务，避免旧 Node 延迟关闭连接而残留读锁。list/show/status/runs 不再触发迁移或被旧 daemon 阻断。写入守卫仅在缺失或定义变化时安装，避免重复打开引起 schema 抖动；Windows teardown 复用已持有的 daemon fence，星期名错误直接指出非法输入。

同步 OpenClaw Roll Core skill 模板中的日历参数、时区、有限轮数和升级诊断说明；明确手动测试会提前产生真实执行，不能替代用户指定的未来开始时间。
