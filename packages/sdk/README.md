# @roll-agent/sdk

用于开发 Roll 子 Agent 的 TypeScript SDK。  
SDK 当前负责封装 MCP Server 的 `stdio` 运行时；远程 `streamable-http` 服务端能力仍由业务方自行实现或部署。

## 安装

```bash
npm install @roll-agent/sdk zod
```
